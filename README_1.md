# Smart Career Roadmap Generator

A beginner-friendly Python Full Stack web application that helps users generate personalized career learning roadmaps based on their current skills and career goals.

The application provides a structured step-by-step roadmap with phases, topics, and progress tracking to guide users toward their desired career path.

---

## Features

- Generate personalized career roadmaps
- User-friendly and responsive interface
- Phase-wise learning structure
- Topic progress tracking
- Frontend and backend integration using REST APIs
- Dynamic roadmap generation

## Installation & Setup
### 1.Clone the Repository
```bash```
git clone <your-github-repository-link>
cd smart-career-roadmap

## Backend Setup
### 2. Navigate to Backend Folder
```bash```
cd backend

### 3. Create Virtual Environment
```bash```
python -m venv venv

### 4. Activate Virtual Environment
```bash```
venv\Scripts\activate [For Windows]
source venv/bin/activate [For Mac/Linux]

### 5. Install Dependencies
```bash```
pip install -r requirements.txt (or) python -m pip install -r requirements.txt

### 6. Apply Migrations
```bash```
python manage.py migrate

### 7. Run Backend Server
```bash```
python manage.py runserver

Backend runs at: ```bash```  http://127.0.0.1:8000/

## Frontend Setup
### 7. Open New Terminal
```bash```
cd frontend

### 8. Install Node Modules
```bash```
npm install

### 9. Start React Application
```bash``` npm start

Frontend runs at: ```bash``` http://localhost:3000/
